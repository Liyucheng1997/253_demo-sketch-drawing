# 绘境学堂 · 素描与山水画学习

一个纯前端的绘画学习网页应用，涵盖**素描**与**中国山水画**两大画风。无需任何后端与依赖，打开 `index.html` 即可使用。

## 功能

### 📚 系统教程（12 课）
- **素描**：握笔与排线 · 透视原理 · 几何体结构 · 明暗五调子 · 质感表现 · 完整作品流程
- **山水画**：文房执笔 · 墨分五色 · 皴法详解 · 树法点景 · 云水留白 · 三远构图
- 所有示意图（排线、五调子球体、披麻/斧劈/雨点皴、鹿角蟹爪枝等）均由 Canvas 程序化绘制，无外部图片依赖

### 🖌️ 练习画板
- 四种笔触模拟：铅笔（颗粒排线）、炭笔、毛笔（速度控制粗细 + 洇墨软边）、橡皮
- 内置 5 个**分步临摹示范**：排线基本功、素描球体、两点透视立方体、平远山水小品、墨竹一枝
- 半透明底稿逐步显示，可调透明度；支持撤销、清空、导出 PNG

### 🔍 上传画作解析
- 上传任意画作，在浏览器本地完成图像分析（不上传服务器）
- 自动分解为 5 个绘制阶段：构图大形 → 线稿提取 → 铺大调子 → 分层深入 → 完成对比
- 每步生成参考图与专业技法要点，支持「素描画法 / 水墨画法」两套解析思路
- 自动识别影调、对比、色彩倾向与光源方向

### ✨ AI 素描（Claude Opus 5.5）
- 在页面里填入自己的 Claude API Key（可选「记住在本机浏览器」），说一句话就能画
- Claude 先设计构图、光源和五大调子，输出一份结构化的「素描绘制方案」；页面边接收边用铅笔线条、交叉排线、擦笔、橡皮提亮一笔笔画出来，并标出当前步骤（构图 → 线稿 → 铺调子 → 深入 → 高光）
- 画完可以继续说怎么改，每次修改生成新版本，可前后切换、重播绘制过程、保存 PNG，或一键送到练习画板当底稿临摹
- 浏览器直接调用 `api.anthropic.com`（官方 `@anthropic-ai/sdk`，从 jsDelivr 按需加载），费用计入你自己的账户；Key 不会发往其他地方

## 使用

直接双击 `index.html`，或启动任意静态服务器：

```bash
python -m http.server 8244
```

然后访问 http://localhost:8244 。

## 技术

原生 HTML / CSS / JavaScript，Canvas 2D 图像处理（灰度、盒式模糊、色调分离、Sobel 边缘检测），除 AI 素描按需加载 Anthropic SDK 外零依赖。
